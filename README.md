### About me

- I design web interfaces and build front-end applications.
- I maintain BornInTeyvat, an open-source Genshin Impact character birthday tracker and dataset for Vietnamese players.
- I write browser userscripts, ad-block filters, and client mods to fix annoying web layouts.
- I use AI coding tools to speed up prototyping and ship side projects faster.
